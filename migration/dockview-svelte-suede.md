# Migrating `dockview-svelte-suede` to suede v2

> The mechanics are in [any-suede-dependency.md](./any-suede-dependency.md);
> this records what *this* repository looks like and what is specific to it.
>
> Migrate before `sweater-vest-suede`, which depends on it. Nothing depends on
> this repository other than that, so it can go in the first wave.

## Where this repository stands today

Verified against `main`:

| | |
| --- | --- |
| Shape | **1 — pre-upgrade** (`.suede/core` absent, `.github/workflows` holds only `subrepo-push-release.yml`) |
| Suede dependencies | **none** — `release/.gitrepo` is the only `.gitrepo` in the tree |
| Manifest | `release/.dependencies/package.json` — legacy path |
| **Also** | a stray `.dependencies/package.json` at the **repo root** |
| Separator | `.` — Svelte and TypeScript (`DockView.svelte`, `config.ts`, `utils/`) |

`suede list` reports nothing and `suede check` passes. Root entries are
`release/`, `src/`, `tsconfig/` and the stray `.dependencies/` — no suede
dependencies among them.

## The thing specific to this repository

**There are two dead manifest directories, not one.** Besides the legacy
`release/.dependencies/`, an even earlier layout left a `.dependencies/` at the
repository root holding a `package.json`. Nothing reads it — not v1, not v2 —
and its presence next to the real thing is exactly the kind of ambiguity that
makes someone edit the wrong file later.

Delete both in step 4:

```bash
git rm -r release/.dependencies
git rm -r .dependencies
python3 .suede/core/suede.py extract
```

Note the shapes are *not* interchangeable: the manifest suede publishes is
`release/.suede/.dependencies/`, generated by `extract`. A directory called
`.dependencies` anywhere else is a leftover.

## What to do

Follow [the general guide](./any-suede-dependency.md) as **shape 1**, all six
steps, with:

- **Step 4** — the two removals above. Expect
  `release/.suede/.dependencies/package.json` and no `.gitrepo` records, since
  this repository has no suede dependencies.
- **Step 5** — the separator is `.`:
  ```bash
  mkdir -p .suede/.dependencies && printf '.\n' > .suede/.dependencies/separator
  ```

## Stop and ask if

- `git rm -r .dependencies` removes something with content you recognise. It
  should hold only a generated `package.json`; anything else was put there by
  hand and is worth reading before deleting.
- `suede list` reports anything. `src/` and `tsconfig/` are ordinary folders,
  not subrepos, and should not appear.
